# 섀도 응답 비교 하네스 (S2-06)

edge 를 별 프로세스로 뜯어내기 전에, **모놀리스와 edge 의 응답이 같은지** 결정적으로 확인하는 도구다.
2단계 완료 판정 ②(기존 API 응답 동일, 설계 §8-3)의 근거를 만든다.

## 왜 새로 만들었나

설계 §9-1 은 "섀도잉 도구로 `qa/load/k6` 시나리오 11개를 재사용한다"고 적었지만 **재사용이 성립하지 않는다.**
edge 담당 경로(`/api/catalog`·`/api/orders`·`/images`·`/virtual-queues`)를 커버하는 자동 회귀가
`qa/**` 전체에 **0건**이다(k6 11개·Playwright 10개 모두 해당 경로 문자열 없음). 즉 edge 가 가져갈 경로는
지금 어떤 자동 회귀에도 걸려 있지 않다.

nginx `mirror` 로 실트래픽을 복제하는 방식은 채택하지 않았다 — 미러 응답은 폐기되어 **비교할 수 없다**.
결정적 코퍼스 replay 가 더 단순하고 재현 가능하다.

## 구성

| 경로 | 역할 |
|---|---|
| `corpus/*.json` | 경로별 요청 목록(선언). 배열 순서가 실행 순서다 — 상태를 바꾸는 요청(대기열 입장·이탈)이 있어 두 대상에 같은 순서로 보낸다 |
| `lib/compare-core.mjs` | 비교 규칙(순수 함수) — 정규화·차이 수집·판정 |
| `compare.mjs` | 실행기 — 코퍼스 로드 → 로그인 → 두 대상 호출 → 비교 → 리포트 |
| `test/*.test.mjs` | 비교 규칙 단위 테스트 + 실행기 종단 테스트 |
| `results/` | 리포트 출력(비커밋) |

## 실행

```bash
# 자기 검증 — 양쪽을 같은 대상으로 지정하면 불일치 0건이어야 한다
node qa/shadow/compare.mjs --baseline http://localhost:8080 --candidate http://localhost:8080 \
  --empty-user qa-empty@example.com

# 2단계 섀도 (S2-15) — baseline 모놀리스 vs candidate edge
node qa/shadow/compare.mjs --baseline http://localhost:8080 --candidate http://localhost:8081
```

종료 코드: `0` 불일치 0건 · `1` 불일치 있음 · `2` 판정 불가만 있음(재실행 대상) · `64` 사용법·안전 위반.

로컬(`localhost`·`127.0.0.1`·`*.local`) 이외 대상은 실행 전에 차단한다 — `qa/load/k6/lib/auth.js` 의
`assertSafeTarget` 과 같은 원칙이다.

## 비교 규칙 — 무엇을 계약으로 보지 않는가

| 요소 | 처리 | 근거 |
|---|---|---|
| 동률 항목의 순서 | 비교 제외 | 파사드가 `sortedByDescending(createdAt)` 하나만 쓴다 — 동률의 상대 순서는 원본 조회 순서에 따라 갈리고 계약이 아니다. **정렬 키 시퀀스 자체는 비교하므로** 정렬이 실제로 달라지면 불일치로 남는다 |
| presigned URL 의 서명·만료·날짜 값 | 값만 제외, 키·host·path·나머지 쿼리 값은 비교 | 매 호출 달라진다. 티켓은 "키 집합만 비교"였지만 한 단계 좁혀 **볼라틸 키의 값만** 버린다 — 키가 같으면서 값이 바뀐 실제 계약 변화(버킷·리전 등)를 놓치지 않기 위해서다 |
| `failedDomains` 비어 있지 않음 | **판정 불가**(불일치 아님) | 부분 실패는 타임아웃 의존이라 부하에 따라 달라진다. 재실행 대상으로 분리한다 |
| 전송 실패 | 판정 불가 | 대상이 안 떠 있는 것과 응답이 다른 것을 구분한다 |

4xx 케이스를 코퍼스에 반드시 포함한다 — 오류 응답 본문은 `GlobalExceptionHandler` 가 만들고 그것을
edge 가 자기 것으로 갖게 되는 것이 S2-02 다. 여기서 검증되지 않으면 오류 계약 드리프트가 전환 후에 드러난다.

## 테스트

```bash
node --test qa/shadow/test/*.test.mjs
```

비교기 자신이 틀리면 "불일치 0건"이 아무것도 보장하지 않는다. 그래서 규칙을 실행기와 분리해
서버 없이 잠그고, 실행기는 스텁 서버로 종단 검증한다(같은 대상 → 불일치 0건 / 한쪽 드리프트 → 검출).

## 범위

- **실행은 S2-15 다.** 이 디렉토리는 도구만 제공한다.
- 실제 모놀리스를 baseline·candidate 로 지정하는 자기 검증에는 dev 스택이 필요하다.
